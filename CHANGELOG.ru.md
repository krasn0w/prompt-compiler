# Changelog

[English](CHANGELOG.md) · **Русский**

Все значимые изменения проекта фиксируются здесь. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/).

## [3.0.0] — 2026-10-07

### Added

- Профили моделей с подгрузкой по требованию из `references/models/` (Claude, OpenAI GPT, Gemini, DeepSeek), у каждого — источники и дата проверки.
- Явный уровень действия (информировать, спланировать, изменить) и секция `Autonomy` с условием завершения и правилами остановки для агентных промптов.
- Замена просьб выписать рассуждение просьбой о кратком обосновании.
- Разметка вставленного пользователем текста для целевых моделей Claude.
- Адаптации для дизайна и исследований: нежелательные приёмы только со слов пользователя; пометка неподтверждённого.
- Необязательный блок параметров запуска в выводе.
- Приоритет явных инструкций пользователя над скиллом.
- Набор регрессионных случаев в `tests/regression/cases.md`; детерминированные проверки профилей и длины описания.

### Changed

- Короткое описание скилла с одним исключением.
- Профиль Claude обновлён под Claude 5.x; профиль OpenAI — под GPT-6 и GPT-5.6; профиль Gemini — под Gemini 3.x; профиль DeepSeek разделён на V4 и устаревший R1.
- Размещение длинного контекста: порог 20k+ токенов отнесён к рекомендации вендора, ~2k токенов остаются правилом проекта.
- Инструкции о размышлении и проверке подбираются по модели, а не добавляются по умолчанию.
- Карта доказательств: двенадцать новых утверждений; цифры GPT-5.6 о коротких промптах перенесены из перепроверки в ориентировочное заявление вендора.

### Removed

- Повтор ключевых ограничений в конце длинного промпта.
- «Consider / evaluate вместо think» как общее правило для Claude; осталось только для Claude Opus 4.5 с выключенным мышлением.
- Советы по параметрам выборки вне устаревшего раздела DeepSeek-R1.

### Migration

- Устанавливайте папку проекта целиком: один `SKILL.md` больше не содержит профилей моделей.

## [2.1.0] — 2026-09-01

- Полные комплекты документации на английском и русском языках.
- Переключатели языка в README, аннотации, changelog и карте источников.

- Английский стал основным языком документации на GitHub.

## [2.0.1] — 2026-09-01

### Added

- Публичная документация проекта и аннотация.
- Проверяемая карта источников и границ применимости.
- Детерминированная проверка структуры проекта и GitHub Actions.

## [2.0.0] — 2026-08-02

### Added

- Семиступенчатый pipeline компиляции.
- Адаптация по типу задачи и целевой модели.
- Режим `compile → stop` по умолчанию.
- Допустимый no-op для уже достаточного промпта.
- Проверка критической неоднозначности, противоречий и prompt injection boundaries.
